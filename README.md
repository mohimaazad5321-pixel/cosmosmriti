# CosmoSmriti

This project was built with [Lovable](https://lovable.dev).

**Live app**: <https://cosmosmriti.lovable.app>

## Development

You need [Bun](https://bun.sh).

```
git clone https://github.com/mohimaazad5321-pixel/cosmosmriti.git
cd cosmosmriti
bun install
bun run dev
```

## Build

```
bun run build
```
